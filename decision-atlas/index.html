Why an AI decision needs boundaries

Before you run the framework

Capability is not permission.

The six gates ask whether a decision is valuable, bounded, operationally feasible and reversible—not merely whether a model can produce it.

01 / Run a decision

Six gates. The strictest one decides.

Start from a worked case or your own. Each gate crosses two axes on a 3 × 3 matrix; each axis is placed by two evidence questions, not by a guess. When in doubt, pick the weaker answer: unknown is not medium.

Decision memo

The doctrine behind the gates

Minimum sufficient decision-grade data. Reuse that lowers marginal cost. Capability relative to complexity. Own differentiation; rent commodity. Design for reversibility. Measure value per scarce resource.

05 / Turn the call into a brief

The Nine Answers.

Business problem → Decision → User → Data → Intelligence → Action → Control → KPI → ₹. Each answer is checked for sharpness as you type: a number where a number belongs, an owner, a baseline, a stop rule.

06 / How to read this

These are judgment aids, not validated scoring models. The bands and calls make reasoning explicit and arguable; they do not grant permission to act. Real decisions still need tested evidence, explicit authority and a named, accountable owner. Worked cases are fictional.
