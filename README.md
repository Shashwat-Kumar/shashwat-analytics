# ReadSigil

[ReadSigil](https://readsigil.com/) is an independent publication and hands-on lab for better decisions in the age of AI.

It publishes original analysis, practical learning and browser-based experiments using fictional or synthetic data. Founded and edited by [Shashwat Kumar](https://readsigil.com/about.html).
