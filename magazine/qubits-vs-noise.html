Qubits vs noise

Why error rates matter more than qubit counts. Stylised model for intuition, not a simulation of any real device.

Stylised rule of thumb: logical error ≈ 0.1 × (p / pth)(d+1)/2, with threshold pth = 1% and about 2d² physical qubits per logical qubit (surface-code style). Real thresholds, constants and overheads differ by hardware and code. Below threshold, a bigger code helps; above it, a bigger code hurts.
